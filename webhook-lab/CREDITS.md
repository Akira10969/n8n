## 🗣️ Voice Engine & Web Audio
The character voices (UNIT-7, Sarah, The Void) are procedurally generated in real-time entirely within the browser using the **Web Speech API**. Background music crossfading, ducking, and generative glitch sound effects (UI Beeps, Radio Clicks) are rendered on-the-fly using the **Web Audio API**. No external CDNs or API keys are required for the audio engine.
