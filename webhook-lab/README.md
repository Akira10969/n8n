# Webhook Learning Roadmap

An interactive, comprehensive web application designed to teach the fundamentals of Webhooks and Event-Driven Architecture. Built with React and Vite, this course transforms dense technical concepts into an engaging, visual learning experience.

## 🚀 Features

- **24 Structured Theory Levels**: Covers everything from basic HTTP concepts to advanced topics like Message Queues, Serverless Functions, and HMAC Security.
- **7 Fully Guided Capstone Projects**: Interactive labs that guide you through building real-world webhook integrations, including:
  - Building a local Node.js receiver and tunneling with ngrok.
  - Setting up GitHub webhooks with cryptographic signature verification.
  - Automating customer support routing using OpenAI and n8n.
  - Building a production-grade Webhook Gateway in Express.
- **Interactive Quizzes**: Knowledge checks at the end of every module with visual feedback and detailed explanations.
- **Progression System**: A structured, lock-and-key module progression system that tracks your learning path.
- **Premium Design**: A modern UI featuring a glassmorphism aesthetic, sleek dark mode styling, and smooth micro-animations.

## 🛠 Tech Stack

- **React 18**
- **Vite**
- **React Markdown & Remark GFM** (for rendering robust course content)
- **Mermaid.js** (for visualizing complex architectural diagrams)
- **Vanilla CSS** (custom modern design system)

## 💻 Getting Started

Follow these steps to run the Webhook Learning Roadmap locally on your machine.

### Prerequisites
- Node.js (v18 or higher recommended)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Akira10969/n8n.git
   cd n8n/webhook-lab
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to the URL provided in your terminal (typically `http://localhost:5173`).

## 📚 Curriculum Overview
The course is broken down into modular chunks for easy consumption:
- **Levels 1-7**: The Basics (Internet, HTTP, JSON, APIs vs Webhooks)
- **Levels 8-15**: Intermediate Concepts (Data payloads, HMAC Security, Troubleshooting, Retries)
- **Levels 16-24**: Advanced Architecture (Event-Driven Architecture, Message Queues, Serverless, Async Processing)
- **Projects 1-7**: Hands-on, practical engineering applications of the theory.
